# Ebook 项目学习路线

> 这套文档按“**硬件 → 驱动 → 中间层 → UI → 应用**”的顺序组织。
> 每一份文档都尽量做到：**代码在哪、手册哪一页、这一步为什么这样做、常见坑是什么。**

---

## 0. 先记住学习方法

不要一上来从 `main()` 往下硬读。推荐按这条原则：

```text
先跑通一条完整链路
  → 再回头看每一层的实现
  → 最后扩展到其他模块
```

每学一个模块，问自己三个问题：

1. 这个模块的输入是什么？
2. 这个模块的输出是什么？
3. 它和上下游是怎么连接的？

## 2. 每个模块怎么学

### 第 1 步：先看“这条链路”

比如触摸：

```text
手指按下
→ FT6336U 拉低 INT
→ GPIO 中断
→ 输入任务被唤醒
→ I2C 读坐标
→ 手势状态机
→ UiBus 队列
→ UI 线程
```

先把这条链路的“箭头”画出来，再去看每个箭头对应的代码。

### 第 2 步：再看“每个函数的职责”

看到函数时，先问：

- 它接收什么参数？
- 它返回什么？
- 它失败时怎么办？
- 它会被谁调用？

### 第 3 步：最后看“为什么这样写”

比如：

- 为什么中断里不读 I2C？
- 为什么事件要进队列，而不是直接调用页面？
- 为什么局刷要按 8 像素对齐？
- 为什么 BUSY 要等？

这些问题在对应模块的文档里都会解释。

## 3. 每个模块的“自测问题”

学完一个模块后，尝试不看文档回答：

### 墨水屏

- RST、BUSY、D/C#、CS# 分别是什么？
- 0x12 是什么命令？
- Full / Fast / Partial 三种波形有什么区别？
- 为什么第一次刷新要用 Full？

### 触摸 FT6336U

- INT 中断为什么只发信号量？
- I2C 读点的寄存器是什么？
- Tap / Swipe / LongPress 分别在什么条件下产生？
- 为什么坐标要裁剪和翻转？

### 按键与拨码

- 一个 ADC 引脚怎么区分三个档位？
- 为什么要连续采样多次？
- 按键事件最后怎么变成页面操作？

### 显示链路

- Router、Composer、Presenter、Canvas 各负责什么？
- UiBus 队列满了怎么办？
- 为什么 Presenter 只保留最新一帧？

### 存储与 USB

- FAT32 和 LittleFS 各用在哪里？
- TF 卡热插拔怎么发现？
- USB MSC 和应用同时访问存储会怎样？

### 网络

- Wi-Fi 连接状态怎么回到 UI？
- NTP 时间同步后怎么通知界面？
- BLE 和 Wi-Fi 能同时开吗？

### 音频

- I2S 的 MCLK / SCLK / LRCK / DIN / DOUT 各是什么？
- ES8311 怎么配置？
- 功放使能是哪个 GPIO？

### 电源与电池

- 5V 怎么变成 3.3V？
- 3.3V 怎么升到 +12V 给墨水屏？
- 电池电量怎么采样？

## 6. 代码根目录

```text
main/
├── app/
│   ├── ebook/        # UI、应用、输入、显示管线
│   ├── network/      # Wi-Fi、BLE
│   ├── protocol/     # HTTP、NTP、WebSocket
│   └── system/       # 任务、电源、事件
├── bsp/
│   ├── config/       # GPIO / 硬件参数
│   ├── driver/       # 屏幕、触摸、音频、按键、IMU
│   └── i2c/          # I2C 总线
└── common/           # 存储、内存、OTA
```
